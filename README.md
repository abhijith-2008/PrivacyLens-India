# 🔍 PrivacyLens India

> **A student project exploring how privacy-policy text can be made easier to review.**

Privacy policies are often long, legally dense, and filled with technical jargon. Crucial details about data collection, usage, sharing, retention, and user choices get buried. **PrivacyLens India** is a proposed web application that helps users parse and locate relevant information in privacy policies quickly and efficiently.

---

## ⚠️ Disclaimer
**PrivacyLens India is an educational prototype, not a legal compliance checker.** 
* It does not provide legal advice and is not a substitute for reading the original policy or seeking professional counsel.
* The machine learning models and text-matching rules may yield incomplete or incorrect predictions. 
* A detected phrase is not proof of legal compliance, and a missing match is not proof of non-compliance.

---

## ✨ Features & Outputs

Users can simply paste the privacy policy of any website or application into the Streamlit interface to receive three distinct analyses:

1. **📝 Extractive Overview** 
   A concise summary generated by intelligently selecting the most informative sentences directly from the original policy text.
2. **🏷️ Privacy-Practice Classification** 
   Identifies possible privacy-practice categories associated with specific passages. It utilizes a text-classification model (trained on the OPP-115 dataset) and displays supporting excerpts from the text where available.
3. **🇮🇳 DPDP Topic Checklist** 
   An informational checklist checking for wording related to key topics from India's **Digital Personal Data Protection (DPDP)** framework using transparent text-matching rules.

*(Note: The initial scope is limited to analyzing manually pasted text; automatic website crawling is not supported.)*
